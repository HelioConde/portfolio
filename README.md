# Portfólio — Primeira versão

**Um dos meus primeiros portfólios de desenvolvimento front-end, preservado como registro de aprendizado.**

## Objetivo

Apresentar projetos, experiências e tecnologias exploradas durante minha evolução como desenvolvedor web.

## Tecnologias estudadas

HTML5, CSS3, JavaScript, jQuery, AJAX, Bootstrap, PHP, MySQL, Node.js, Electron e React.

A lista representa tecnologias estudadas ao longo do percurso, **não significa que todas sejam utilizadas dentro deste repositório**.
