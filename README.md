## Por que este repositório continua aqui?

Este foi um dos meus primeiros espaços para **apresentar estudos, habilidades e projetos de front-end**. Ele preserva decisões de layout, estrutura HTML e recursos visuais de uma etapa anterior da minha trajetória.

O site original contém `index.html`, estilos, scripts de navegação, imagens e páginas de apresentação. A versão atual do portfólio é mantida **separadamente**, sem precisar substituir este registro.

## Tecnologias deste site

**HTML5, CSS3 e JavaScript**, com recursos e bibliotecas históricas presentes nas pastas do projeto.

A lista de conhecimentos do portfólio antigo inclui outras tecnologias estudadas ao longo do tempo; isso **não significa que todas façam parte do código-fonte deste repositório**.

## Visualizar localmente

```bash
git clone https://github.com/HelioConde/portfolio.git
cd portfolio
python -m http.server 8000
```

Abra `http://localhost:8000`.

| Pasta | Conteúdo |
| --- | --- |
| `css/` | Layout e estilos |
| `js/` | Interações |
| `img/` | Imagens do portfólio |
| `certificado/` | Material relacionado à formação |
| `icon/`, `font/` | Recursos gráficos e fontes |
